# Week 3 — CSS Basics Practice

**Student:** Alan Yangen

This repository contains 15 CSS practice exercises divided into three levels.

## Topics
- CSS selectors and the box model
- Text styling, colors, and fonts
- Positioning
- Flexbox and Grid
- Transitions and hover effects
- Responsive design with media queries

## Structure
- `index.html` — project home page with links to all exercises
- `css/styles.css` — shared external stylesheet
- `beginner/` — Exercises 1–5
- `intermediate/` — Exercises 6–10
- `challenging/` — Exercises 11–15

## Run locally
Open `index.html` in a browser. Each exercise page links to the shared external CSS file.

## GitHub Pages
In the GitHub repository, open **Settings → Pages**, select **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then save.
